# Manuscript Workflow

1. Establish the requested outcome, target audience, and any venue, length, or
   style constraints from the supplied material.
2. Inspect only the sources and workspace files relevant to the task. Separate
   verified source material from assumptions and proposed text.
3. For drafting or revision, provide a coherent structure and make claims no
   stronger than the supplied evidence permits. Preserve equations, citations,
   and terminology unless the user asks to change them.
4. For review, identify concrete strengths, risks, missing evidence, and
   prioritized revisions. Do not claim external verification that was not done.
5. Before completion, check that the output answers the requested task and that
   any changed workspace artifact exists and is readable.
