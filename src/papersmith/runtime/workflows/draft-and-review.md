# Draft and Review Workflow

## Drafting

1. State the intended contribution and audience based on supplied material.
2. Propose or follow an outline that connects motivation, method, evidence,
   limitations, and conclusion.
3. Draft concise prose with explicit transitions and qualified claims.
4. Mark missing citations, data, or methodological details as open items.

## Reviewing

1. Read the requested manuscript scope and supporting material.
2. Separate factual observations from editorial recommendations.
3. Report prioritized, actionable changes with the affected section or passage.
4. Finish with unresolved evidence or reproducibility questions.
